 # NovaBank Dashboard

NovaBank is a responsive interactive banking dashboard built with HTML, CSS and JavaScript.

It simulates a modern digital banking experience with transfers, savings, transaction history and card controls.

## Features

- Interactive account balance
- Send money / transfer simulation
- Transaction history
- Savings balance
- Card freeze and unfreeze controls
- Responsive layout
- LocalStorage support so demo data can persist in the browser

## Built With

- HTML5
- CSS
- JavaScript
- LocalStorage

## Run Locally

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

For the best experience, use VS Code with the Live Server extension.

## Demo Notice

NovaBank is a front-end demonstration project.

It does not connect to a real bank, process payments, access real accounts, or handle real financial information.
